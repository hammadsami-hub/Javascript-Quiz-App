# JavaScript Quiz App

An interactive, timed quiz app built with HTML, CSS, Bootstrap and vanilla JavaScript. Answer 10 JavaScript questions against a 15-second timer per question and see your final score at the end.

## Features

- 10 multiple-choice JavaScript questions
- 15-second countdown timer per question (turns red in the last 5 seconds)
- Instant feedback: the correct answer turns green, a wrong choice turns red
- Auto-reveal of the correct answer when time runs out
- Live score and progress bar
- Result screen with score, percentage and a message
- Play again without reloading the page
- Fully responsive layout (mobile, tablet, desktop)
- Keyboard-accessible buttons with visible focus

## Tech Stack

| Technology | Purpose |
| --- | --- |
| HTML5 | Structure of the screens, questions and buttons |
| CSS3 + Bootstrap 5 | Styling and responsive layout |
| JavaScript (ES6) | Quiz logic, timer, answer checking and scoring |
